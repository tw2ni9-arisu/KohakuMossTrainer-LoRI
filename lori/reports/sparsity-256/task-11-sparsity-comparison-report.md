# 稀疏 LoRI 稀疏度对比：移除 90% / 60% / 30%（保留 10% / 40% / 70%）

**结论先行。** 三份稀疏包（移除 90%/60%/30%，即保留 10%/40%/70%）与 Base、稠密 285/570/900 在同一 12 行、同一配方下渲染成 13 列网格。先给出四条可核对的事实：

1. **起点可信。** 12 份导出逐份通过：`read_lori_state` 可读、252 层的 A/alpha 与 task10 的 initial-hashes **504/504 逐张量一致**、`b_values` 元素数逐档等于掩码保留数且**全部非零**、`active_indices` 与掩码逐层逐位一致；多列渲染路径经 canary **4/4 位级相同**（重放稠密 285/570 的 r00/r14），与归档稠密列同一数值路径。
2. **相对 Base 的偏移。** 稠密三列随步数单调增大（28.58 → 30.78 → 33.60）。**稀疏 90% 几乎不随步数变化、且与稠密 285 相当（28.28 → 28.28 → 29.06）**；60% 与 30% 在 285 就跳到 32.83 / 32.37（高于稠密 285），570 回落（30.82 / 31.58）、900 回升（31.27 / 33.76，与稠密 900 的 33.60 基本持平）。
3. **与稠密同 step 的距离。** 在 570 与 900 上**随保留比例单调**：30%（保留 70%）最近（14.52 / 15.23），60% 居中（17.88 / 18.08），90% 最远（22.96 / 23.92）。**285 处不单调**：90% 最近（16.86），60% 最远（19.44），30% 居中（19.14）。
4. **同 step 三档互比。** 60% 与 30% 始终最接近（8.07 / 14.26 / 16.15），90% 与 30% 最远（17.74 / 20.34 / 23.13），并且 90% 与另两档的分离随步数增大。同稀疏度跨步看，90% 的三列彼此最像（15.75 / 12.18 / 18.77，低于稠密的 23.77 / 22.22 / 27.87）——**90% 在三步之间几乎没有继续学习**。

视觉上，90% 列在 12 行里都保持与 Base 同级的构图与可读面部，是最"保守"的一列；60%/30% 在 285 就出现深发色与更强对比的改写，900 列则复现了 task10 稠密 900 的漂移形态（r00 深蓝发色与眼睛不对称、r08 版面重排且右侧人物面部空白）。因此**本轮不支持"越稀疏越差"这类质量排序**：90% 更像"没学到多少"，30% 最接近稠密但同样继承了稠密 900 的退化。像素差只度量同种子输出偏移，不是质量或泛化判据。

## 10. 限制

1. 全部 285 张训练图都参加了训练，本轮**没有独立留出集**；三档稀疏各 900 步只相当于约 3.16 个数据轮次，且只有一条 seed 轨迹。
2. **没有真人盲评**：本报告的视觉判断来自单人（本人）对缩略图与 8 张原图的观察，未做盲评打分；分组 sheet 与 13 列网格已按可盲评的形式提供，但尚未密封评分。
3. **起点不同**：本轮 calibration 的 B 与 task10 稠密 285 的 B 不是逐值复现（0/252 层相同，最大绝对差 8.99e-3），A/alpha 相同。因此稠密 285 列与稀疏 285 列的差异里包含"B 不同源"的成分，不能读成纯稀疏度效应。
4. **像素差不是质量排名**：MAE 只度量同种子输出偏移；行内标准差（7.4–10.4）与列间均值差同量级，且 r00/r08 这类行本身就不稳定。
5. **场景与种子有限**：3 个场景 × 2 个种子（12 行），每组只有一条 seed-42 与一条 seed-43 轨迹；没有跨 checkpoint 的重采样重复，无法估计采样噪声。
6. **稀疏度只有三档、每档一条轨迹**；60% 与 30% 在 285 处"比稠密更远"这一观察需要第二条种子/训练重复才能确认不是单次训练波动。
