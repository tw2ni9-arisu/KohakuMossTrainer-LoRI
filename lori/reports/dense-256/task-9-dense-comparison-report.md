# LoRI 第 232 步稠密 B 与稀疏 B 同种子出图

**稠密 B ×1 在六行中都比稀疏 B ×1 更大幅度地改变了 Base 输出。** 星空组里最明显的是金色虹膜高光、发丝和衣褶阴影的细化，粉色双人与海边组也改变了发型、服饰和取景。三组没有呈现一致的触发词效应，现有样本不足以判断稠密组的画风还原或成图质量更好。 [三列对照图](../../../experiment/task9/comparison-20261118-a/matched-grid.png)

原生 `compare_grid` 一次生成 18 张 512×512 单图，每行共用提示和种子，列依次为 Base、稀疏 B 232 ×1、稠密 B 232 ×1。沿用同一 INT8 ConvRot 主干、文本编码器与 VAE，使用 BF16、Euler 50 步、CFG 3、shift 5、two-pass CFG、batch 1、`minimal` 显存档。每个场景只在第一行加 `nigenmame, `。前两行重放 Task8 的 r04/r05 提示和 seed 42，其四个 Base／稀疏 B 图块与归档解码 RGB 哈希完全一致。两份第 232 步原生导出及三个基础权重的 SHA256 在 CPU 预检中核对通过。 [冻结记录](../../../experiment/task9/comparison-20261118-a/freeze.json) · [完整提示、参数和单图索引](../../../experiment/task9/comparison-20261118-a/images/metadata.json)

- **紫发星空。** 稠密组两行都把人物转成相近的微侧姿态，用更细的发束线条、暖金色眼部高光和更清楚的蓝白衣褶明暗。无词图还出现类似参照 `110959357_p0` 的小金色扣件。两列都保留了提示要求的深蓝蝴蝶结、托脸动作与环形行星，稀疏无词组的开肩、袖口和蝴蝶结已经与稠密相似。提示本身明确指定了紫发、金眼、海军服和星空。 [有词稀疏](../../../experiment/task9/comparison-20261118-a/images/r02_c01.png) · [有词稠密](../../../experiment/task9/comparison-20261118-a/images/r02_c02.png) · [无词稠密](../../../experiment/task9/comparison-20261118-a/images/r03_c02.png)
- **海边夕阳。** 三列都保留双人、夕阳、海面与仙女棒。稠密有词图强化了飞扬发束与裙褶，无词图改变右侧外套颜色、加大人物占比，右侧人物的一只脚被画面裁掉。参照 `112715321_p1` 使用海滩蹲姿和更强的前景点光，三列仍以提示中的堤岸站姿和逆光为主。这里最明显的证据来自取景和服饰变化。 [有词稀疏](../../../experiment/task9/comparison-20261118-a/images/r04_c01.png) · [有词稠密](../../../experiment/task9/comparison-20261118-a/images/r04_c02.png) · [无词稠密](../../../experiment/task9/comparison-20261118-a/images/r05_c02.png)
