# LoRI 在 MOSS-Image 上的低显存适配实验

## 这是什么

这里记录的是一组在 MOSS-Image 图像生成模型上进行的 LoRI 适配器训练实验。MOSS-Image 的核心是一个扩散 Transformer（DiT）主干。我们不改动主干本身，而是在它上面挂载小型的适配器，只训练这些适配器，让模型学会某种特定的画风或某个角色。

训练数据是 285 对图文，每一对都是一张动漫风格的插画加上一段文字描述，描述中带有触发词。实验的目标很具体：在一张 12GB 显存的消费级显卡上，完成风格与角色的学习。
## 训练方法

整个流程分为两个阶段，主干在训练中始终冻结。

- 基础模型以 INT8 量化方式加载以节省显存，计算使用 BF16 精度。主干的参数不参与训练。
- 适配器中的 A 矩阵先随机初始化，之后固定不变，整个训练过程都不更新；只训练 B 矩阵。
- 第一阶段是稠密校准：B 矩阵的全部位置都参与训练（A 仍然固定），共 285 步（约相当于把全部数据学一遍）。这一阶段结束后，得到 B 中各个位置数值大小的分布。
- 第二阶段按数值的全局大小，只保留最大的一部分位置（比如 10%、40% 或 70%），其余位置清零。此后只训练被保留的位置，优化器的状态也只为这些位置分配，而不是为整个矩阵分配。通常说的稀疏度 90%、60%、30%，指的是被移除的比例，对应保留 10%、40%、70%。
- 第二阶段共训练 900 步，学习率固定为 1e-4，不做权重衰减。

为了把显存控制在 12GB 以内，训练器做了几件事：主干按层流式加载，不用的部分先放到主机内存里；激活值和梯度可以卸载到主机内存；优化器状态也放在主机内存中。实测 900 步训练的显存峰值约为 2.4 GiB。整个 900 步训练约需 1.56 小时，每步的中位耗时为 6.05 秒。

训练过程中会在若干步保存检查点，每个检查点都可以导出为推理用的文件，并可以在 ComfyUI 等工具中加载。

## 要点

1. 固定的 A 矩阵是写在结构里的，不是靠事后检查才确认的。它在训练中不会被更新，导出的文件里也注明了冻结标记和指纹，方便核对。
2. “稠密 B”的 900 步实验（A 固定、B 不做稀疏）不是论文意义上的 LoRI，只是一个对照组，用来衡量“稀疏”本身带来的差别。
3. 稀疏 LoRI 的 ComfyUI 导出，是把掩码展开后得到的推理版本。它适合用来出图，但不能拿来继续训练。
4. 同样是 90% 稀疏，在约 1024 级的原生分辨率下训练，比在 256 分辨率下训练更能保留原图的构图与配色（900 步时平均偏移分别为 26.1 与 29.1，数值越小越接近基准）。不过两组设置还有训练分辨率、采样分辨率等其它差异，不能完全归因于分辨率本身。
5. 数据量很小，没有留出的测试集，也没有真人盲评。结论只限于对输出画面的观察和量化偏移，不代表模型的泛化能力，也不能直接推广到其它风格或角色。

## 结果一览

下表中的数字是各设置生成的画面与基准（未加适配器的原模型）之间的平均像素偏移，数值越大，画面离基准越远。

| 设置 | 保留的 B 位置 | 900 步时偏移 | 偏移随训练步数的变化 |
| --- | --- | --- | --- |
| 稠密对照（256 分辨率，B 不稀疏） | 100% | 33.6 | 28.6 → 30.8 → 33.6（285 → 570 → 900 步） |
| 稀疏 30%（256 分辨率） | 70% | 33.8 | 32.4 → 31.6 → 33.8（285 → 570 → 900 步） |
| 稀疏 60%（256 分辨率） | 40% | 31.3 | 32.8 → 30.8 → 31.3（285 → 570 → 900 步） |
| 稀疏 90%（256 分辨率） | 10% | 29.1 | 28.3 → 28.3 → 29.1（285 → 570 → 900 步），几乎不变 |
| 稀疏 90%（原生分辨率） | 10% | 26.1 | 16.2 → 23.3 → 26.5 → 26.1（250 → 550 → 850 → 900 步） |

在原生分辨率的 90% 稀疏设置中，550 步之后画面的变化明显变小，850 步与 900 步的结果几乎无法区分。

显存方面，原生分辨率 90% 稀疏的 900 步训练，显存峰值为 2.4263 GiB，全程保持一致。

## 如何复现

复现这一实验需要以下条件：

- MOSS-Image 的模型权重；
- 本仓库中的 KohakuMossTrainer 训练器（LoRI 相关分支）；
- 显存 12GB 以上的 NVIDIA 显卡，以及较大的主机内存（本实验使用的机器为 64GB 内存）；
- 数据集：每张图片配一个同名的文本文件，文本中写明触发词与描述。

大致流程如下：

1. 整理图文数据，并预先计算文本编码与图像潜变量的缓存，使训练时不必再加载庞大的文本编码器。
2. 进行 285 步的稠密校准，得到 B 的数值分布。
3. 按照目标稀疏度生成掩码，只保留相应比例的位置。
4. 在掩码约束下训练 900 步，并在若干检查点导出推理文件。
5. 用导出的文件生成对照图，计算与基准的偏移。

具体的操作步骤、命令和参数，请参见 INDEX.md 以及训练器仓库中的文档。
